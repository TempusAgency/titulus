## Правила (окрім кадрів)

- Сегменти: **identity** (id у верхній грані + роль у тілі) → **vitals** (CTX,
  ліміти 5h/7d, eta, модель, effort) → **activity** (`⠹ agents`, `⚙ wf`,
  `⇅ coord`) → **place** (теки).
- **activity з'являється ТІЛЬКИ коли є що показати.** У спокої сегментів три,
  не чотири.
- Кольори: активний контур — терракота `217;119;87`, неактивний — `58;69;92`.
  Текст ролі `245;246;250` жирний, лічильники `158;162;172`, шлях
  `124;138;162`, приглушене `110;114;124`.
- **Спільна рейка світиться, якщо активний хоч один із двох сусідів.**
- **Другий канал сигналу поза кольором:** активна рейка — подвійна `═`,
  неактивна — одинарна `─`. Має працювати при `NO_COLOR=1`.
- «Активний» = маркер `.working` АБО біжать agents/wf. Координаційна пошта
  сегмент показує, але НЕ підсвічує.
- Гліф активності: спокій `✻`, рух `✺` (є ще ряд `✦✶✷✸✹` для анімації).
- Гілка — `↱` (U+21B1). НЕ `⎇` — його немає в шрифтах стеку, він ламається.
- Роль обрізається на 160 символів.
- Вузька ширина <60: злиття identity+vitals, з лічильників лише CTX.
- `…` для обрізаних шляхів.
